### Rule compliance (SKILL.md 15 rules + reject list)

The grep for hex, palette, primitive ramps, `dark:`, `duration-`/`ease-`, `outline-none`, `react-aria-components`, `style={{`, `transition-all` and `shadow-` found nothing in either file. The `className` values on library components are `self-start` and `w-full` only (opus `tsx:211,412,427,459-465`; sonnet `tsx:202-211`). One primary per section holds for both. `Key` is imported from `react-aria` (type only), which is fine.
Soft issues, all reported by the models:

- Rule 10 grey zone: standalone hand-styled `<a>` for the section, stock names, teaser titles (opus `tsx:142,253,224`; sonnet `tsx:117,252,347,406`). Both include the focus ring.
- Opus `Badge` wrapped in `<a>` (`tsx:125`) because `Badge` has no `href`, though page-patterns says the ticker badge is "always a link".
- Sonnet imports demo data (`site-header.demo`, `site-footer.demo`), which doesn't ship in the package. It was reported.
- Sonnet's bordered card inside the reading page goes against `layout-reading-page` and `layout-one-card-level`. This was not reported.

### Accessibility

- Both: one `h1`, `h2` per section, `aria-labelledby` sections, `ButtonUtility` named by `tooltip`, `aria-pressed` follow chips, `role="img"` + label on the photo placeholder, focus ring on hand-written links.
- Opus: the chips' `aria-label` changes with the state ("Følg …" / "Følger …") while `aria-pressed` also changes, so the state is announced twice (`tsx:113-114`). Every teaser save button has the same name, "Lagre i MittFa" (`tsx:239`). The `SiteHeader` has no `menu`, so "Meny" is a dead button (`tsx:523-532`; the library allows this, `site-header.tsx:180`).
- Sonnet: chip names are just the entity ("Andreas Wold Hofstad, toggle button") with no verb (`tsx:95-104`). A `blockquote` is used as a section heading (`tsx:303`). Every link and the stock names point to `href="#"`. "Skriv kommentar" has no handler.
- axe (both, library-caused): ticker red `#e12339` on black is 4.17:1. Avatar initials in `text-quaternary` are 4.18:1. **`text-error-primary` on the `bg-tertiary` inset in dark is 4.44:1**, so every negative change value in a stock inset fails AA in dark. The footer disclaimer link fails `link-in-text-block`.

### Honesty of notes

- Opus: accurate. It lists every stand-in, the rail and ad invention, the kicker choice, the period clash, the hand-styled links and the Badge-in-`<a>`, and says no visual check was done. It omits the missing chart and the INSW "Live" while the market is closed.
- Sonnet: mostly accurate, with gaps. It says the quote is "a standalone bold pull-quote paragraph", but the code (`tsx:303`) is a `blockquote` that renders italic in quotes (point 5 half-flags this). It describes the byline row as "per page-patterns" but leaves out the `SocialButton`s and "Lagre i MittFa" that pattern lists, and doesn't report it. It doesn't report dropping the Live indicator or the company logos.
